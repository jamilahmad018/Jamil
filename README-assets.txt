Add these files to this folder:

- profile-photo.jpg   — your headshot, used on the About / Home pages
- og-image.jpg        — 1200x630px image used when the site is shared on
                         social media (LinkedIn, Twitter/X, WhatsApp, etc.)
- thesis.pdf           — your full thesis, linked from research.html

None of these are required for the site to work — pages will simply show
a blank space or a broken image link until you add real files with these
exact names. See README.md in the project root for full instructions.
